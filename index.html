Thinkorswim 觀察面板設計整理

核心目的：把美股 equity 的「昨收 → 今日開盤 → 現在」拆成可直接判讀的三段價格行為。

Gap%昨收 → 今日開盤
%FromOpen今日開盤 → 現在
RTH %變動昨收 → 現在

1. 設計目的

這套觀察面板不是只問「今天漲多少」，而是進一步區分：開盤前市場已經完成多少重新定價，以及 09:30 開盤之後真正的買賣方向。

昨日收盤 → 今日開盤 → 最新價

2. 最終欄位配置

欄位計算方式用途
Gap%(今日開盤 - 昨收) / 昨收 × 100%隔夜 / 盤前造成的跳空
最新價Current / Last Price目前成交價格
FromOpen最新價 - 今日開盤開盤後漲跌多少美元
RTH 淨變動最新價 - 前一個 RTH 收盤價相對昨收的美元變動
%FromOpen(最新價 - 今日開盤) / 今日開盤 × 100%開盤後真正的漲跌幅
RTH %變動(最新價 - 前一個 RTH 收盤價) / 前一個 RTH 收盤價 × 100%相對昨收的總漲跌幅

3. 三個核心百分比的差別

假設：昨收 100、今日開盤 105、現在 103。

Gap% = +5.00%：開盤前市場已經先把價格往上重定價。

%FromOpen ≈ -1.90%：09:30 開盤後其實是在下跌。

RTH %變動 = +3.00%：相對昨收仍然上漲。

4. 為什麼 %FromOpen 對 RTH 交易特別重要

一般的 % Change / RTH %變動 以昨收為基準，因此會把「隔夜 / 盤前 Gap」和「09:30 開盤後的盤中走勢」混在一起。若交易者主要在 RTH 才執行交易，%FromOpen 更接近真正可交易區間的價格行為。

例如昨收 100、開盤 110、現在 108：RTH %變動 = +8%，但 %FromOpen ≈ -1.82%。也就是說今天仍大漲，但開盤後其實在被賣。

5. Gap% × %FromOpen 的判讀

Gap%%FromOpen常見解讀
++高開後續強，continuation
+-高開後被賣，fade / rejection
-+低開後反彈，reversal
--低開後續弱，continuation lower

6. 數學關係

(1 + RTH Return) = (1 + Gap Return) × (1 + FromOpen Return)

漲跌幅較小時，可以粗略理解為 RTH Return ≈ Gap Return + FromOpen Return。

7. Thinkorswim 自訂欄位

A. FromOpen

def spot = close;
def dayOpen = open(period = AggregationPeriod.DAY);

plot Diff = spot - dayOpen;

Diff.AssignValueColor(
    if Diff > 0 then Color.GREEN
    else if Diff < 0 then Color.RED
    else Color.GRAY
);

B. %FromOpen

def spot = close;
def dayOpen = open(period = AggregationPeriod.DAY);

def pct = (spot - dayOpen) / dayOpen * 100;

AddLabel(
    yes,
    if pct > 0 then "+" + AsText(pct, "%1$.2f") + "%"
    else AsText(pct, "%1$.2f") + "%",
    if pct > 0 then Color.GREEN
    else if pct < 0 then Color.RED
    else Color.GRAY
);

使用 AddLabel() 後會偏向文字輸出；如果主要用途是排序，建議另保留純數值版本。

C. Gap%

def dayOpen = open(period = AggregationPeriod.DAY);
def prevClose = close(period = AggregationPeriod.DAY)[1];

def gapPct = (dayOpen - prevClose) / prevClose * 100;

AddLabel(
    yes,
    if gapPct > 0 then "+" + AsText(gapPct, "%1$.2f") + "%"
    else AsText(gapPct, "%1$.2f") + "%",
    if gapPct > 0 then Color.GREEN
    else if gapPct < 0 then Color.RED
    else Color.GRAY
);

8. 最終觀察面板邏輯

代號 | Gap% | 最新價 | FromOpen | RTH 淨變動 | %FromOpen | RTH %變動
  1. Gap%：開盤前市場做了什麼
  2. 最新價：現在價格在哪
  3. FromOpen：開盤後漲跌多少美元
  4. %FromOpen：開盤後實際漲跌多少百分比
  5. RTH 淨變動：相對昨收漲跌多少美元
  6. RTH %變動：相對昨收今天總共漲跌多少

9. 核心用途

這套設計的核心不是單純看「今天誰漲最多」，而是把價格行為拆開，辨認：

  • 隔夜已經大漲，但開盤後轉弱
  • 隔夜沒什麼動，但開盤後大量買盤湧入
  • 高開後繼續加速
  • 低開後被快速承接
  • 低開後繼續走弱

如果主要在 RTH 執行交易，%FromOpen 可以作為判斷「開盤後真正相對強弱」的核心欄位。
